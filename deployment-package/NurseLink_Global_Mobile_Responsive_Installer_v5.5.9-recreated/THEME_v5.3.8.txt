NurseLink v5.3.8 — Administrator Light Blue Theme
=====================================================

SCOPE
-----
Administrator surfaces only.

Primary Administrator Sign In:
https://app.amsertech.com/admin/login.html

Administration Operations Center:
https://app.amsertech.com/admin/

THEME
-----
The Administrator interface now uses a calm light-blue operational palette:

- very-light-blue Administration sidebar
- pale-blue active navigation state
- navy-blue text for strong readability
- white cards with soft blue borders
- subtle blue shadows
- light-blue forms/toolbars
- existing green/orange/red/purple semantic status colors retained
- Administrator Login uses the same light-blue family

MEMBER LOGIN
------------
The Member login visual design is intentionally unchanged.

The NurseLink member nurse montage, public-auth layout, and member login styling
are not restyled by this release.

DELIVERY
--------

repair script in this package deploys the light-blue Administrator assets
directly and verifies the theme markers before HTTPS validation.
